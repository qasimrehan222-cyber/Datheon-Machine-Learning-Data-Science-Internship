# Task 1: Iris Dataset Classification

This task compares Logistic Regression and Decision Tree classifiers on the Iris dataset.

## Files

- `Iris_Dataset_Classification.ipynb` — Google Colab notebook
- `iris_dataset_classification.py` — Python export of the notebook
- `iris.csv-iris  Dataset.csv` — dataset used by both files

## Run in Google Colab

Open the notebook in Colab and run the cells from top to bottom. When the upload cell appears, upload the CSV file in this folder. The notebook expects its exact filename, including the two spaces before `Dataset.csv`.

The Python export uses `google.colab.files.upload()`, so it is intended to run in Google Colab. The notebook and script use pandas, NumPy, Matplotlib, Seaborn, and scikit-learn.
